# raspberry-pi-otomatik-web-kurulum-script
php, apache gibi bir çok hizmeti tek tıklamayla kurar, sadece, raspberry pi osta çalışır.

## Kullanım
```
sudo python3 kurulum.py
```
Kurulanlar: Apache, PHP (Raspberry Pi OS deposundaki güncel sürüm), MariaDB, phpMyAdmin, Pure-FTPd.
Oluşturulan parolalar `/root/kurulum-bilgileri.txt` dosyasına yazılır.
